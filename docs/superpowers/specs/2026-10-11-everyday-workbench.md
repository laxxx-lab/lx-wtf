# Lilith im Alltag und als Arbeitsfläche des Agenten

Der Nutzer beauftragt Kontextarbeit, Alltagsroutinen und natürliches Weiterreden
aus der geprüften Recherche, Windows-Autostart, die Veröffentlichung im bereits
angelegten Repository `laxxx-lab/lx-wtf` sowie eine moderne, leicht transparente
Werkstatt. Bestehende Session, Modelle, Live-/Standby- und Sensorzustände bleiben
die Grundlage. Bereits erteilte Zustimmung gilt; keine erneute Freigaberunde.

- Kopierte Texte und das ausdrücklich angesprochene Fenster werden erst auf
  Anfrage gelesen. Fensteridentität wird vor Öffnen der Werkstatt festgelegt
  und danach geprüft. Quelldaten sind begrenzt, vertrauliche Felder gesperrt,
  Text als untrusted Daten an die ausgewählte Session übergeben. Letzte Quelle
  erscheint als aufklappbare Karte, nicht als ungefragtes Bildschirmtracking.
- Bestehende Modi erhalten Ordner und HTTP(S)-Seiten einschließlich lokaler
  Entwicklungsseiten. Alltagssätze wählen konfigurierte Modi/Abläufe. Einzelne
  Öffnungsannahmen werden nicht zu bestätigtem Gesamterfolg umgedeutet.
- „Stopp“ beendet aktuelle Arbeit/Sprache mit ehrlicher Bestätigung; es ist
  getrennt von Not-Aus/Datenschutz. Folgefragen bleiben in derselben Session.
- Die Werkstatt wird lesbar aus dunklem Glas, ruhigem Cyan und gezieltem Amber
  gestaltet. Ihre sieben Reiter, Browsergeometrie, Streams und gespeicherte
  Monitorlage bleiben erhalten. Native Acrylic-Unterstützung bekommt einen
  lesbaren Fallback; keine Verringerung der Textdeckkraft.
- Agentenpräsentation bekommt eine Anforderungs-ID und öffnet ohne Fokusraub.
  Nur eine passende aktuelle Agenten-Präsentation darf der Agent schließen.
  Benutzerinteraktion übernimmt die Werkstatt, sodass verspätetes Agenten-
  Schließen die manuell verwendete Fläche nicht ausblendet. Agent kann Quellen,
  Graph, Browser und Artcraft gezielt präsentieren; Skill/API werden konkret
  dokumentiert und im bestehenden Hermes installiert.
- Windows-Autostart wird für diesen Benutzer eingeschaltet und anhand der
  exakten Electron-/Workspace-Registrierung einschließlich StartupApproved
  geprüft. Ein Reboot wird nicht ausgelöst.
- Veröffentlichung: Quellcode, Dokumentation, Tests und Installationshinweise.
  Keine Tokens, Cookies, privaten Fotos, Stimmen, Modelle oder Laufzeitdaten.
  Keine neue Lizenz ohne ausdrücklichen Lizenzwunsch. Bestehender Checkout
  bleibt erhalten; neue unversionierte Arbeiten erfordern seine Wiederverwendung.
  Leeres Ziel-Repository wird regulär ohne Force-Push befüllt.
